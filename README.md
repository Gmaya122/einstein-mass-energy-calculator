# einstein-mass-energy-calculator
E = mc² Calculator
A Python implementation of Einstein's famous mass-energy equivalence formula.
What it does
Takes a mass value (in kilograms) as input and calculates the equivalent energy in joules using the formula E = mc², where the speed of light is 300,000,000 m/s.
How to run
bashpython einstein.py
Example:
m: 5
E: 450000000000000000
Concepts used

User input with input()
Integer conversion with int()
Exponentiation with **
String formatting and type conversion with str()
